# CVFix-SA

### Your CV. Your Career.

CVFix-SA is a web application designed to help users:

- Upload a CV
- Analyse a CV against a job description
- Identify matching keywords
- Identify potential missing keywords
- Improve CV wording
- Generate a CV document

## Supported files

- PDF
- DOCX

## Future development

CVFix-SA will later include more advanced AI-powered semantic
matching and CV optimisation.
